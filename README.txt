黄桃保鲜包装调研成果网站
========================

一、怎么打开
------------
双击 index.html 即可。纯静态页面，不需要服务器、不联网也能看，
所有样式与脚本都内嵌在 HTML 里，图片在 assets/img/ 下。

如果要放到网上，把整个 huangtao-site 文件夹上传到任意静态托管
（GitHub Pages、Cloudflare Pages、校内服务器均可）。


二、结构与分区
--------------
沿用优秀调研报告网站的十一区块结构，但内容按黄桃保鲜主题重排：

  1  top         首屏：标题、四个关键数字、团队合影
  2  tldr        概览：产业、损耗、分界、方案四张卡
  3  background  研究背景：政策脉络 + 产业规模与落差
  4  journey     调研历程：6/24 至 7/2 的五个节点
  5  method      研究方法：问卷、访谈、观察、实验四种
  6  findings    核心发现：三条结论，带数据标签
  7  segments    场景化方案：伴手礼、电商、暂存三套规格
  8  outputs     成果产出：报告、图表、实验、方案、成本、推广
  9  advice      对策建议：对农户、对企业、对政府三层
  10 gallery     实践影像：九张现场照片
  11 feedback    留言区：存本机浏览器，不上传


三、设计说明
------------
配色为黄桃色系：深褐底（#1a0f08）+ 黄桃橙（#ffc107）+ 米白文字，
衬线字体做标题、无衬线做正文。与调研报告的图表配色一致。

交互只有三处，都是轻量的：
  · 顶栏锚点跳转
  · 滚动淡入（IntersectionObserver）
  · 留言（localStorage）

没有引入任何外部框架、字体 CDN 或统计脚本，离线可用。

六、修改指引
------------
页面由 build_site.py 生成，不建议直接改 index.html。
改内容就改 build_site.py 里的 HTML 字符串，改样式改 CSS 变量：

  --peach-400   主色（黄桃橙）
  --ink-900     背景色（深褐）
  --cream       文字色（米白）
  --maxw        内容最大宽度（1160px）

改完运行 python build_site.py 重新生成，再跑三个 check_site 脚本复查。
